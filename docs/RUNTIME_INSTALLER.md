# Runtime installation / Установка runtime

**В 0.3.1 отдельная кнопка Install runtime убрана.** Текущий порядок:
**Select GSI → Browse files → .img → Start**. Start проверяет наличие среды,
автоматически подготавливает отсутствующую и продолжает проверку запуска.
Неполная среда не перезаписывается. При закрытии приложения во время подготовки
запуск после установки отменяется. Ниже описан сам механизм установки, добавленный
в 0.3.0; отдельная кнопка относится только к версии 0.3.0.

**0.3.1:** import `.img` and press **Start**; missing-environment preparation is
automatic, followed by launch checks. The separate button below describes 0.3.0.

В 0.3.0 добавлена кнопка **Install runtime** и отдельные пакеты для Evolution X и
ColorOS. APK скачивает пакет по закреплённому HTTPS URL и SHA-256; пользователю
не нужно вручную создавать `gsionlocked-profile.properties`.

## Первый запуск

1. Скачай APK 0.3.0 и подходящий образ из [раздела загрузок GSI](GSI_DOWNLOADS.md).
2. Распакуй архив до `.img`. В APK выбери **Select GSI → Browse files** и импортируй
   этот `.img`. Кнопки **Use prepared…** предназначены для уже установленной среды.
3. Нажми **Install runtime**, разреши root и оставь приложение открытым до конца.
   Пакет Evolution X занимает примерно 255 МБ, ColorOS — 556 МБ. Реальные файлы
   среды занимают больше места; дополнительно сохраняется отдельная копия `.img`.
4. Дождись сообщения об успешной установке. **Start** отдельно проверит условия
   запуска. Установщик не запускает гостевую прошивку автоматически.

Образ и runtime должны соответствовать друг другу. Импорт `.xz`, `.zip` или
отдельной `.001` вместо распакованного `.img` не поддерживается. Для Evolution X
размер гостевых данных выбирается через **Storage** и выделяется при запуске.
Недостаток свободного места останавливает подготовку с сообщением.

## Совместимость первых пакетов

Пакеты собраны для существовавших портов SM-S911B / One UI FZG1, Android 16 /
ARM64. Имя модели не проверяется, однако framework хоста должен совпасть с ABI
контрактом пакета. Несовместимый framework останавливает установку **до скачивания**.
Это не универсальная адаптация S23 к любому Xiaomi, Pixel или другому Samsung.
Для другого firmware нужны соответствующие адаптеры и новый runtime-пакет.
Для подготовленного ColorOS требуется KernelSU с busybox/resetprop.

## Что делает установщик

- Проверяет SHA-256 исходного `.img` и всего ZIP, затем каждого файла в ZIP.
- Создаёт отдельный временный каталог. Не выполняет установочные shell-скрипты
  из скачанного архива и не записывает физические разделы.
- Берёт заявленные совместимые библиотеки из `/system` и `/apex` **этого** телефона.
  Чужие `/data`, EFS, аккаунты, PIN, биометрия и данные приложений в пакет не входят.
- Проверяет копию `.img`, права и структуру среды до её публикации.
- Для EvoX записывает профиль запуска последним. При проверяемом сбое публикации
  убирает уже опубликованные новые файлы; существующие каталоги не перезаписывает.
- Сохраняет One UI работающей. Переход в гостевую систему происходит только через
  отдельное нажатие **Start**.

При наличии старого runtime установка остановится, сохранив его данные. Обновление
поверх существующей среды и восстановление после принудительного убийства процесса
не заявлены как проверенные сценарии. Не закрывай приложение во время подготовки.

## Проверки и пределы

По просьбе владельца выпуск проверен **без телефона**. Оба настоящих ZIP прошли
полную проверку содержимого и SHA-256. На тестовых файловых системах прошли
установка обеих схем, копирование библиотек хоста из fixture, отказ при неверном
образе, сохранение существующих данных и откат после сбоя публикации. Проверки
архива отсекают выход за каталог, подмену родителя ссылкой, пропущенные файлы и
попытки включить пользовательские данные. Android APK собран и подписан.

Свежая установка этими пакетами на физическом телефоне и последующий запуск
гостевой системы ещё не проверены. Предыдущие успешные запуски портов не заменяют
такую проверку нового установщика. Баги ColorOS с паролем/PIN, возможной недоставкой
SMS и сохранением root после возврата этим выпуском не исправляются.

## Package format

`runtime.properties` contains `format=1`, `system`, `gsi.sha256`, an exact
`host.services.sha256`, declared roots, `sha.<relative path>`, file modes, optional
host-component copies and links. ZIP payload entries must be declared under
`payload/`. The APK catalog pins the complete ZIP digest. A GSI image or a saved
userdata volume must never be embedded in a runtime package. The installation
engine is in RuntimeBundle, RuntimeFiles and RuntimeInstallMain; corresponding
offline tests are in tests/. Runtime archives retain upstream component licenses.
