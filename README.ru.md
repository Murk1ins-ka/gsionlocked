## gsionlocked — Booting GSI via Treble Userspace Takeover

### 0.3.1: Samsung и подготовка портов OneOS

Добавлен экран **Compatibility / Совместимость** с локальным отчётом и распознаванием
13 комбинаций модель/codename/SoC из OneOS. Это справочные профили для портирования,
**не включённый запуск на 13 моделях**. Перенесены патчеры framework, native/overlay
исходники, контракты staging и таблицы хешей. Session-скрипты OneLineage исключены
из нового snapshot из-за отдельного ограничения в upstream NOTICE.
Готовые runtime по-прежнему рассчитаны на S23/FZG1; backend для других Samsung
и хостов Android 17 ещё требуется реализовать и проверить.
[Таблица моделей, анализ и план портирования](docs/SAMSUNG_PORTING.md).

### Как правильно скачать и установить

1. Открой [релиз v0.3.1](https://github.com/Murk1ins-ka/gsionlocked/releases/tag/v0.3.1-samsung-preview), раскрой **Assets** и скачай **`gsionlocked.apk`**. Архивы **Source code** и `gsionlocked-source.zip` — исходники для разработчиков, на телефон их устанавливать не нужно.
2. Открой [образы GSI в релизе v0.2.0](https://github.com/Murk1ins-ka/gsionlocked/releases/tag/v0.2.0-coloros-preview). Выбери **одну систему**:
   - **Evolution X:** скачай `EvoX-11.11-GSI_treble_arm64-ab-GAPPS-20260920.img.xz`.
   - **ColorOS:** скачай **все четыре части** `OneOS_ColorOS17_FindX9Ultra_IN.img.zip.001`–`.004` в одну папку.
3. Распакуй образ на компьютере. Для распаковки с проверкой скачай из того же релиза `restore-gsi.py` и `GSI-MANIFEST.json` в папку с архивом. Установи Python 3 и выполни в этой папке **одну** команду: `python restore-gsi.py evolution` или `python restore-gsi.py coloros`. Скрипт проверит архивы и итоговый образ. [Размеры, SHA-256 и подробности](docs/GSI_DOWNLOADS.md). Оставь место под архивы и распакованный образ: одна ColorOS занимает около 12,07 ГБ.
4. Перенеси полученный **`.img`** на телефон и установи APK в One UI. Восстанови root. Требования хоста: **Android 16 / ARM64**, совместимый framework S23/FZG1; для ColorOS также нужны KernelSU busybox/resetprop. **Не выбирай в приложении `.xz`, `.zip` или `.001`.**
5. В приложении нажми **Select GSI → Browse files → выбери распакованный .img → Install runtime**. Разреши root и оставь приложение открытым. Оно само скачает нужный runtime: примерно **255 МБ для Evolution X** или **556 МБ для ColorOS**. Вручную распаковывать ZIP runtime не нужно. Установщик проверит свободное место: нужна отдельная копия образа и дополнительное место для гостевых данных.
6. Дождись завершения установки, нажми **Start** и прочитай подтверждение. Перед ColorOS отключи PIN/пароль и биометрию в One UI. **В ColorOS пароль/PIN, отпечаток и Face Unlock не поддерживаются; входящие SMS и коды Google могут не приходить.**

Существующий runtime не перезаписывается. При несовпадении framework нужен совместимый порт. Новый установщик проверен офлайн; свежая установка и последующий запуск на физическом телефоне ещё не проверены. [Подробная инструкция](docs/RUNTIME_INSTALLER.md) · [Готовый пост для Telegram на русском и английском](docs/TELEGRAM_POST.md).

### 0.3.0: установка runtime для ColorOS и Evolution X

Появилась кнопка **Install runtime**. Первый запуск: **Select GSI → Browse files →
импорт распакованного .img → Install runtime → Start**. Пакеты скачиваются отдельно
с проверкой SHA-256. [Инструкция и ограничения](docs/RUNTIME_INSTALLER.md).
Первые пакеты предназначены для существующего S23/FZG1 порта; универсальная
совместимость с другими телефонами не заявляется. Новый установщик проверен
офлайн, без свежего запуска прошивки на телефоне.

### 0.2.1: снята блокировка по модели

Название модели, codename и версия загрузчика больше не блокируют Samsung в приложении.
Входные требования текущего загрузчика: **Android 16 / ARM64**, root и совместимый
подготовленный runtime. Другие модели **не проверены**: это снятие ограничения,
а не готовый универсальный порт. Для ColorOS сохраняются проверки framework
хоста, образа и манифеста комплекта S23; на другой прошивке они могут остановить
запуск. Старые подготовленные бинарные runtime не обновляются установкой APK.

### Добавлена ColorOS 17 / Find X9 Ultra IN

В **0.2.0-coloros-preview** сохранён интерфейс проекта. В **Select GSI** теперь
есть отдельные карточки EvoX и ColorOS, а также импорт `.img`. ColorOS запускается
через собственный подготовленный профиль S23 с проверкой файлов и SHA-256 образа.
В гостевой системе есть кнопка **Return to One UI**; возврат выполняет перезагрузку.
Альтернатива — обе кнопки громкости в течение трёх секунд. После перезагрузки
временный root нужно восстановить.

GSI: **`OneOS_ColorOS17_FindX9Ultra_IN.img`**, Android 17 / SDK 37, raw ext4,
**12 069 945 344 байт**. SHA-256 распакованного образа:

```text
a36ef550f4b2530fb9c7c6d363180d9eb4437e0497ebc87292697e4bf2a580b0
```

AOD отключается при каждом запуске ColorOS, адаптивные **120 Гц** сохранены.
Проверены скачивание Firefox, выбор файла через системный проводник и загрузка
на локальный сервер, операции MediaStore и сохранение JPEG в Open Camera.
Пароль, отпечаток и Face Unlock в ColorOS **не поддерживаются**; результаты EvoX
ниже к ним не относятся. Нужен совместимый комплект для конкретного хоста;
в 0.3.0 он устанавливается отдельно кнопкой **Install runtime**. Архивы ColorOS и
Evolution X добавлены отдельными вложениями в релиз: [скачивание и распаковка](docs/GSI_DOWNLOADS.md).
[Подробности и ограничения ColorOS](docs/COLOROS.md).

Подготовленный EvoX запускается поверх работающего ядра Samsung без прошивки физических системных разделов и полной перезагрузки ядра. Приложение проверяет root, образ и runtime; загрузчик создаёт отдельные пространства монтирования, Binder, свойств и сети. Guardian передаёт управление службами и оборудованием от OneUI гостевой системе. Затем запускаются гостевые Zygote, SurfaceFlinger и Android framework. При завершении guardian возвращает OneUI; обе кнопки громкости в течение двух секунд запрашивают возврат.

Проверен **KernelSU**. Совместимость исключительно с TEMPROOT не подтверждена. Текущий код не использует `ksud soft-reboot`, глобальную подмену `/system` или модуль magic-mount. Гостевые данные сохраняются между сеансами. Нулевой риск и полная работоспособность оборудования не гарантируются; результаты указаны в [таблице проверок](docs/COMPATIBILITY.md).

## Исправление установки из Play Маркета

В runtime **198** исправлено подключение гостевого FUSE-хранилища к пространству установщика, время жизни ART-службы и наследование сетевых ограничений UID. После возврата в OneUI и повторного запуска EvoX пользователь подтвердил загрузку и установку из Play Маркета. Приложение 0.1.2 проверяет runtime 198 или новее перед запуском и показывает включённые исправления в журнале. На тестовом телефоне runtime уже установлен; обновление одного APK на другом телефоне не подготавливает среду автоматически.

Использованный GSI: **Evolution X (EvoX) 11.11, Android 16 / SDK 36**, сборка **20 сентября 2026**, ARM64 A/B Treble, вариант с GApps.

Исходный архив: `EvoX-11.11-GSI_treble_arm64-ab-GAPPS-20260920.img.xz`. Размер распакованного raw ext4 образа: **3 863 474 176 байт**. SHA-256 именно распакованного `.img`, а не архива:

```text
5e8333e15798592bae059bcb78ba85394418afc8f035a13fc0e97c086b8c1e49
```

Другие версии EvoX не считаются автоматически совместимыми. Архив образа доступен отдельно в релизе; в исходники и APK он не включён.

Проверено: **Samsung SM-S911B (dm1q), OneUI S911BXXSAFZG1, EvoX 11.11 Android 16**. Более свежие прошивки, другие региональные варианты, S23+ и Ultra пока не проверены. Имя модели не блокирует запуск; нужен runtime для конкретного устройства.

В приложении есть выбор GSI, импорт `.img`, проверка SHA-256, проверка root, настройка памяти и реальные команды запуска. Для неподдерживаемого образа запуск блокируется. Архив `.xz` сначала нужно распаковать.

**Это экспериментальный preview.** После установки APK импортируй образ и нажми **Install runtime**. Первые пакеты предназначены для совместимого S23/FZG1 хоста. Автоматическая подготовка проверена офлайн, проверка новой установки на телефоне ещё впереди. Не публикуйте этот выпуск как «любой GSI на любом Samsung».

Образы GSI, файлы Google/Samsung, пользовательские данные, отпечатки, PIN и ключ подписи в репозиторий не включены. Сборка приложения автономна относительно исходной рабочей папки: Python, JDK 17, Android SDK 35 и NDK 25.2.9519653. Команды сборки и документация находятся в [README.md](README.md).

Для подготовленного телефона: **Select GSI → Check root → Storage → Start**. Для возврата в OneUI удерживайте обе кнопки громкости 2 секунды. Runtime временно переключает SELinux в Permissive; guardian возвращает исходные службы и Enforcing. Аппаратный KeyMint гостя пока не реализован.
